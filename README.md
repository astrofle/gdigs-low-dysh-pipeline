# GDIGS-Low dysh pipeline

A [dysh](https://github.com/GreenBankObservatory/dysh) based pipeline for the GBT Diffuse Ionized Gas Survey at Low frequencies ([GDIGS-Low](https://greenbankobservatory.org/science/gbt-surveys/gdigs-low/)).

**The pipeline might change at any point and there's no guarantee it will produce science worthy results.**
